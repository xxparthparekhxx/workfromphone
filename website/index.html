Manual Installation & Server Setup

Deploy on any Linux machine with systemd, standalone CLI, or custom environment variables.

The automated installer downloads the matching binary, validates the SHA-256 checksum, generates an access token, and sets up a systemd user service.

Terminal (Bash) 
curl -fsSL https://raw.githubusercontent.com/xxparthparekhxx/workfromphone/master/scripts/install.sh | bash

Download and extract the standalone binary manually to run it directly from your terminal.

Terminal (x86_64) 
# 1. Create install directory
mkdir -p ~/.local/share/workfromphone/current

# 2. Download and unpack latest x86_64 binary
curl -fsSL https://github.com/xxparthparekhxx/workfromphone/releases/download/backend-v0.1.0/workfromphone-backend-linux-x86_64.tar.gz | tar -xz -C ~/.local/share/workfromphone/current

# 3. Make executable
chmod 700 ~/.local/share/workfromphone/current/workfromphone-backend

# 4. Run with an Access Token
ACCESS_TOKEN="your-secure-random-token" PORT=8000 ~/.local/share/workfromphone/current/workfromphone-backend

Configure a user-level systemd service so the backend starts automatically on boot.

Create Systemd Service (~/.config/systemd/user/workfromphone-backend.service) 
# 1. Create environment file
mkdir -p ~/.config/workfromphone
cat <<'EOF' > ~/.config/workfromphone/backend.env
HOST=127.0.0.1
PORT=8000
ACCESS_TOKEN=your-strong-random-token
DEBUG=false
EOF
chmod 600 ~/.config/workfromphone/backend.env

# 2. Create systemd user service unit
mkdir -p ~/.config/systemd/user
cat <<'EOF' > ~/.config/systemd/user/workfromphone-backend.service
[Unit]
Description=WorkFromPhone Backend Service
After=network-online.target

[Service]
Type=simple
EnvironmentFile=%h/.config/workfromphone/backend.env
ExecStart=%h/.local/share/workfromphone/current/workfromphone-backend
Restart=on-failure
RestartSec=2

[Install]
WantedBy=default.target
EOF

# 3. Reload and start
systemctl --user daemon-reload
systemctl --user enable --now workfromphone-backend.service

# 4. Check status
systemctl --user status workfromphone-backend.service

Route traffic through a Cloudflare Tunnel for secure remote access without opening router firewall ports.

Cloudflare Tunnel Setup 
# 1. Download cloudflared binary
mkdir -p ~/.local/bin ~/.config/workfromphone
curl -fsSL https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 -o ~/.local/bin/cloudflared
chmod 700 ~/.local/bin/cloudflared

# 2. Save your tunnel token
cat <<'EOF' > ~/.config/workfromphone/cloudflared.env
CLOUDFLARE_TUNNEL_TOKEN=eyJh...your-tunnel-token...
EOF
chmod 600 ~/.config/workfromphone/cloudflared.env

# 3. Create systemd unit
cat <<'EOF' > ~/.config/systemd/user/workfromphone-tunnel.service
[Unit]
Description=WorkFromPhone Cloudflare Tunnel
After=network-online.target workfromphone-backend.service

[Service]
Type=simple
EnvironmentFile=%h/.config/workfromphone/cloudflared.env
ExecStart=%h/.local/bin/cloudflared tunnel --no-autoupdate run --token ${CLOUDFLARE_TUNNEL_TOKEN}
Restart=on-failure
RestartSec=3

[Install]
WantedBy=default.target
EOF

# 4. Enable and start tunnel
systemctl --user daemon-reload
systemctl --user enable --now workfromphone-tunnel.service
